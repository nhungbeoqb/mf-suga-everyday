Two lines explaining one everyday thing — a queue — to a 10-year-old. Line 1: a queue is a train made of people, each person hooking on behind the one in front. Line 2: the train fits because both travel in single file and take turns at the front, but it leaves out the engine — a queue has no driver, it only moves because each person chooses to step forward.

## Run it

```sh
python3 main.py
```
